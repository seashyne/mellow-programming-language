# Native Mellow vs Zig benchmark — 2026-06-28

## Environment

- Mellow: `Mellow Programming Language 2.9.7 (Full Native C)`
- Mellow binary: `build/standalone-release/Release/mellow.exe`
- Mellow runtime: `mellow-c`, `x86_64`, `generic-c`, little-endian
- Zig: `0.16.0`
- Zig install: `tools/zig/zig-x86_64-windows-0.16.0/zig.exe`
- Zig mode: `ReleaseFast`, stripped binary
- OS shell: Windows / PowerShell

## Workload

Both programs compute the same integer sum with a `while` loop:

```text
n = 2,000,000
sum i from 0 to n - 1
expected output = 1999999000000
```

Files:

- `benchmarks/native_vs_zig/sum_loop.mellow`
- `benchmarks/native_vs_zig/sum_loop.zig`
- raw JSON: `benchmarks/native_vs_zig/RESULTS_2026-06-28.json`

## Timing method

- 10 full process runs per runtime after one warmup run.
- Measured wall-clock time from process start to process exit.
- Mellow includes source parse/compile/runtime startup.
- Zig measures the already-compiled ReleaseFast executable after the compile step.

## Results

| Runtime | Median ms | Average ms | Min ms | Max ms | Iterations/sec by median |
| --- | ---: | ---: | ---: | ---: | ---: |
| Mellow 2.9.7 Full Native C | 507.27 | 485.07 | 367.96 | 555.91 | ~3.94M/s |
| Zig 0.16.0 ReleaseFast | 8.57 | 10.75 | 7.34 | 32.88 | ~233.30M/s |

Zig 0.16.0 ReleaseFast is about **59.2x faster** on this tight arithmetic loop
by median time.

## Notes

This benchmark stresses VM dispatch, local variable load/store, integer
arithmetic, and loop branching. It does not measure I/O-heavy work, package
loading, native host integrations, MELV, canvas, or stdlib calls.

The likely Mellow runtime optimization targets are still:

1. avoid deep-copying scalar locals on hot `LOAD_LOCAL` paths;
2. specialize integer arithmetic and comparison opcodes;
3. add peephole optimization for `while i < n` loops;
4. reduce tagged-value dispatch overhead;
5. consider a register VM or threaded dispatch for hot bytecode loops.
